Flashing lights

Three options that aren't cheats

Steam flags Pax Autocratica for flashing lights and photosensitive epilepsy, and the bullet-hell battlefields earn that warning. Three options in the Camera tab exist for it:

  • Reduce flashing effects — damps muzzle flash, explosions and strobing
  • Reduce projectile glare — tones down the bullet-hell bloom
  • Disable screen shake

They damp the effect, they don't eliminate it. If you're photosensitive, treat the game's own warning as the one that counts — this is a third-party tool, not a medical safeguard.

Early Access, and what breaks

Read this before filing an issue

Pax Autocratica launched into Early Access on 10 August 2026 and the developers expect roughly two years there. Every patch can move the memory addresses this trainer writes to, which is why something that worked yesterday can quietly stop working today.

Options fail independently — infinite resources can keep running while god mode goes dead. Each release lists the game build it was verified against, so check that first.

Two things ship on by default because of this: read-only mode, which shows live values without writing anything so you can tell whether the trainer still reads the game correctly, and automatic save backup on first attach, because the game syncs through Steam Cloud and a bad write can propagate.

Install in four steps

  1. Download and unblockRight-click the zip, Properties, tick Unblock, Apply. Windows quarantines downloads and the trainer won't attach otherwise.
  2. Extract outside Program FilesDocuments or the desktop is fine. A protected folder breaks profile saving.
  3. Start the game and load a colonyThe process has to exist before the trainer can find it. On Epic, launch through the Epic client.
  4. Run the trainer as administrator, press InsertThe header reads "attached" in red when it's hooked. Turn off Steam Cloud while you experiment.

Questions

Does the Pax Autocratica trainer work with the latest Early Access patch?

Check the releases page, where every build lists the game version it was verified against. The game is in Early Access and patches frequently, which moves the memory addresses the trainer writes to, so expect a short gap between a game update and a matching trainer build.

Will I get banned for using cheats in Pax Autocratica?

No. It is a single-player game with no anti-cheat and no multiplayer, so there is nothing to be banned from. Steam achievements generally still unlock, since they are awarded locally.

Does it work on the Epic Games Store version of Pax Autocratica?

Yes. Both the Steam and Epic Games Store builds are supported. Launch through the Epic client rather than the executable directly, so the process starts with the right environment.

Is Pax Autocratica the same game as Earth From Another Sun?

Pax Autocratica grew out of that project and was renamed. This trainer targets the current Early Access builds only, so old Earth From Another Sun builds and saves are not supported.

Can the trainer reduce the flashing lights in Pax Autocratica?

There are three options for it in the Camera tab: reduce flashing effects, reduce projectile glare, and disable screen shake. They damp the effect rather than removing it. If you are photosensitive, the game's own Steam warning is still the one that counts.

Does it work on Steam Deck or Linux?

No. Windows 10 and 11 only. Proton changes how the game's memory is laid out and this trainer does not handle that.
